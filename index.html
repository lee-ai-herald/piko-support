Piko 技术支持

Piko 是一款 macOS 桌面工作台，包含提醒事项规划板、番茄钟、剪贴板历史和随笔。支持 macOS 13 及以上版本。

联系我们

请在 GitHub 提交问题，我们会在那里回复：https://github.com/lee-ai-herald/piko-support/issues

提交的内容会公开显示，请勿包含密码、私人任务或剪贴板内容。

规划板显示“未连接提醒事项”

在规划板点「继续」并允许访问。如果之前拒绝过，请到「系统设置 › 隐私与安全性 › 提醒事项」打开 Piko。其他功能不需要这项权限。

剪贴板没有记录

剪贴板历史默认关闭，可在剪贴板标签页或「设置 › 工具」中开启。密码管理器标记为机密的内容不会记录。

番茄钟没有通知

请到「系统设置 › 通知」允许 Piko 发送通知，并确认「设置 › 工具」中的「结束时发送系统通知」已打开。

找不到 Piko 窗口

点程序坞或菜单栏的 Piko 图标即可打开。程序坞图标可在「设置 › 通用」中显示或隐藏。

快捷键没有反应

可能与其他应用冲突，可在「设置 › 快捷键」中修改。

试用与购买

App Store 版可免费试用 7 天，到期不会自动扣费；一次性购买后永久使用。换新 Mac 或重装后，在「设置 › 数据与关于 › 购买」点「恢复购买」。

如何使用免费码

macOS 15 或更高版本：打开「设置 › 数据与关于 › 购买 › 兑换优惠码」，输入兑换码。也可以直接打开收到的兑换链接。较早的系统请使用兑换链接，或在 App Store 中点头像，再点「兑换礼品卡或代码」。兑换后回到 Piko，如未自动解锁，请点「恢复购买」。
